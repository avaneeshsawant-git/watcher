User Authentication System

Registration Flow

User submits registration form → Validation (email, password) → Bcrypt hashing
Database insertion with prepared statements → Auto-login session → Redirect to home
Session variables created → Cookie set for "Remember Me" (7 days)

Login Flow

Check existing cookie → Auto-login if valid → Display dashboard
Query database with username → Verify password with password_verify()
Set session variables → Optional "Remember Me" cookie → Secure redirect

Database Architecture

Table Purpose Key Columns Relationships
users User credentials id, username, email, password PK
cart Shopping cart items id, user_id, product_id, quantity FK users.id
orders Customer purchases id, user_id, total, created_at FK users.id
order_items Items in orders id, order_id, product_id, quantity, price FK orders.id
product_reviews Customer reviews id, product_id, user_id, rating, review FK users.id
